# Motion Pulse Remotion Study

A vertical motion design project built with Remotion and React.

## Preview

```bash
npm install
npm run dev
```

The Remotion Studio opens with these compositions:

- `MotionPulse` — 1080×1920, 30 fps, 12 seconds
- `FirstRemotionVideo` — 1080×1920, 30 fps, 24.2 seconds

Voice-over, generated UI sound effects, the motion designer skill, and the supplied reference clip are kept with the project so they remain available after cloning.
